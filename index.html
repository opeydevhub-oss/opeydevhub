A clear process

Good work starts with good questions.

A straightforward path from the first conversation to a useful finished website, with expectations kept clear along the way.

01 / UNDERSTAND ⌕

Start with the need

We clarify the audience, goals, key content and essential features before choosing an approach or writing code.

02 / SHAPE ◇

Plan the experience

Pages and user journeys are organised into a responsive interface, with a clear visual direction and sensible priorities.

03 / BUILD ↗

Build, review, refine

The website is put together, checked across screen sizes and refined against the agreed scope before handover.
